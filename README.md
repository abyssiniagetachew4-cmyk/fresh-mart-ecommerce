# E-Commerce Web Application

This is a full-stack e-commerce web application developed to gain practical experience in modern web development and backend systems.

## Features
- Product listing and categories
- Shopping cart and checkout flow
- User authentication and authorization
- Admin product management
- Order creation and tracking
- Payment integration (Stripe)

## Technologies Used
### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)

### Tools
- Git & GitHub
- RESTful APIs
- Axios / Fetch API

## Purpose
This project demonstrates full-stack development skills, system design, and integration of external services, with a growing interest in scalable and intelligent systems.
